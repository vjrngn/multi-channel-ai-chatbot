# Returns

## Time limit
You can return shoes within 30 days of delivery, as long as they are unworn and in the original box. After 30 days we only accept returns of faulty items.

## Sale items
Sale items can be returned within 14 days of delivery. They are refunded as store credit only, not to your original payment method.

## How to return
Start a return under My Account › Orders › Return. Print the prepaid label, pack the shoes in their box and drop the parcel at any courier point.
